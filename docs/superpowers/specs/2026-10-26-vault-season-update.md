# 0.1.1 宝库与团本范围修订

用户已确认：每个角色任意活动合计开 3 格；新增 BOSS 计划范围为当前赛季全部正式团本。四来源导入与统一展示继续沿用。

- 宝库根据当周采集的独立栏位统计，跨活动合计，达到 3 格完成；缺失、过期、冲突数据保持待确认。奖励装等和上周领奖状态不影响达标。保留旧目标数据用于备份兼容。
- 插件采集冒险指南当前赛季目录 ID，与完整历史团本目录分别存储。桌面选择器只使用明确的赛季 ID，不把最新资料片目录当作最新赛季。未知时提示更新插件采集。
- 复制上周计划跳过旧赛季团本。历史计划、击杀与 ROLL 币记录保留可查可编辑。
- 交付 0.1.1 安装程序、免安装包、更新的游戏插件。验证跨活动目标、未知状态、去重、同资料片旧团本过滤、跨赛季复制、协议兼容及打包启动。

客户端目录实现依据：[Blizzard EncounterJournal UI 源码](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_EncounterJournal/Mainline/Blizzard_EncounterJournal.lua)，Current Season 位于资料片目录之后；缺少可验证赛季目录时不回退显示全部团本。
