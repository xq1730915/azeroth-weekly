# ROLL 币余额修复（0.1.2）

已确认缺陷：插件导出全量货币，桌面总览、角色行和账本用余额数组第一项充当 ROLL 币，导致列表排序和其他货币更新影响余额。对本机导入数据库的只读诊断也复现了错误选择。

修复维持已批准的 ROLL 币余额需求：

- 插件只导出通过客户端名称检查的当前候选币种 3513；读取失败、名称不符明确输出未知，0 保留为 0。
- 共用按明确币种 ID 和最新采集时间选择余额的方法。旧版多货币存档可直接正确读取，不需删除用户数据；不回退到旧赛季币种 3418 或其他货币。
- ROLL 币获取／消耗合计及 BOSS 实际消耗也按同一币种过滤，其他币种历史流水继续可查，并标注币种。
- 验证：Lua 真实执行模拟、乱序多币种选择、0／未知与旧存档兼容、数据库及界面回归；只读核对已有本机数据库；重新构建并检查发布包。

支持范围仍为当前候选币种，需要客户端名称校验；不声称已验证真实游戏实时更新或自动用币归因。
